# Bokhismany Trading SARL - site web

Site vitrine statique (HTML/CSS, sans build) de Bokhismany Trading SARL.

## Déploiement sur Vercel (recommandé)

1. Sur https://vercel.com, clique sur **Add New → Project**.
2. Importe le dépôt `previraza/bokhismany`.
3. Framework preset : **Other**. Laisse les champs de build vides.
4. Clique sur **Deploy**.

Chaque `push` sur `main` redéploie le site automatiquement.

## Mise à jour du contenu

- Les prix et produits se trouvent dans `index.html`, section `#catalogue`.
- Les adresses sont dans la section `#adresses`.
- Les coordonnées sont dans la section `#contact`.
